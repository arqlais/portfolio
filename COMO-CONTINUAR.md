# Como continuar em outra conta do Claude

Tudo o que importa do projeto está aqui no GitHub, no repositório **arqlais/portfolio**: o site, o painel,
o portfólio em PDF, o orçamento e a proposta para moradores. O arquivo `CLAUDE.md` guarda o contexto e o jeito
de trabalhar (prints por dispositivo, PR e merge automáticos, nada de carimbo, identidade do site…).
O Claude da outra conta lê esse arquivo sozinho e continua de onde parou.

## Passo a passo
1. Entre na outra conta em **claude.ai/code**.
2. Conecte o GitHub quando ele pedir, com o **mesmo usuário do GitHub (arqlais)**, e libere o acesso ao
   repositório **portfolio**. Se ele mostrar o link para instalar o app do Claude no GitHub, instale e marque
   o repositório `portfolio` (e o `prompt`, se for continuar o Lavi Prompt também).
   - Se a outra conta do Claude usar **outro usuário do GitHub**, entre no GitHub como arqlais →
     repositório portfolio → Settings → Collaborators → adicione esse outro usuário como colaborador.
3. Crie uma sessão nova escolhendo o repositório **arqlais/portfolio**.
4. Cole esta mensagem para começar:

   > Leia o CLAUDE.md e o COMO-CONTINUAR.md. Sou a Laís, continue o projeto do meu site e do portfólio em PDF
   > do mesmo jeito que vinha sendo feito, fazendo os PRs e o merge você mesmo e me mandando os prints de cada
   > dispositivo.

## O que não muda
- O site **www.lais3d.com.br** e o painel **www.lais3d.com.br/admin** continuam iguais.
- O **token do painel** é seu e fica salvo no seu celular/computador: não depende da conta do Claude.
- O PDF continua sendo gerado sozinho toda vez que você salva no painel.

## O que não passa sozinho (guarde com você)
- **A conversa antiga** não aparece na outra conta. O resumo dela está no `CLAUDE.md`.
- **Arquivos que você enviou no chat**, como o PDF do Canva original. Ele não foi colocado no GitHub de
  propósito: o repositório é público e o arquivo do Canva pode guardar escondido, por baixo dos recortes, o
  carimbo com dados de clientes. Se precisar dele, envie de novo na outra conta.
- **Lembretes agendados** desta conta, se houver algum: peça de novo na outra conta.
