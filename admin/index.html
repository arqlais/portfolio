como consigo meu token? (só na primeira vez)
  1. abra esta página do GitHub (entre na sua conta, se pedir);
  2. em Repository access, escolha Only select repositories → portfolio;
  3. em Permissions → Contents, escolha Read and write;
  4. clique em Generate token, copie o código e cole aqui.

com “manter conectada” marcado, este aparelho lembra o token e nas próximas vezes você já entra direto. use só no seu celular ou computador, e não compartilhe o token com ninguém: ele funciona como uma senha.
